## What is built (saltbuild EXIT=0 at df-101; audit df-audit-025: 269 of 269 theorems within the standard three)
- `VIRDeflate/Bits.lean` (the rest group): S1's reader (`bit`, `bits`, `align`) as S1 writes it, with `>>>` and `&&&`, over
  `ReaderT Env (StateT St (Except String))`. Also D4's recursion: `bitAt`, the bit of a byte, using `Int` `sub`, `lt`, `add` and
  `mul` only. **`bitAt_eq`**: on every byte b < 256 and i < 8, `bitAt b i = (b >>> i) &&& 1`. `stripTop_eq` is the general
  statement: the recursion is the remainder mod 2^(i+1) on its range.
- `VIRDeflate/Huffman.lean` (the canonical-code group): S4's `code` with its two REJECTs and `decode`. There are three modes
  for the incomplete clause. `normal` is S4 as written. `strict` is S6's code-length code ("no exception"). `dist` is S4's
  note: an all-zero distance code is accepted.
- `VIRDeflate/Kraft.lean` (the canonical-code group, with Huffman.lean), green at df-027. With F ℓ = next_code[ℓ] + bl_count[ℓ]:
  - `nextCodes_succ` is S4's loop: F(ℓ+1) = 2·F ℓ + bl_count[ℓ+1]. `F_eq_sum`: F ℓ = Σ_{k ≤ ℓ} bl_count[k]·2^(ℓ−k).
  - `leftAfter_eq`: S4's `left` is 2^15 − F 15, and the loop rejects iff F 15 > 2^15.
  - **`oversubscribed_iff`**: "over-subscribed" iff the Kraft sum exceeds 1.
  - **`complete_iff`**: `left = 0` iff the Kraft sum is exactly 1.
  - **`prefix_free`**: no code at a shorter length is a prefix of a code. With `lookup_some`, that is decode's uniqueness.
  - `codes_fit`: when the code is not over-subscribed, every ℓ-bit code is below 2^ℓ.
  - **`complete_covers`** (df-032, STATUS 294) is completeness's converse. When `left = 0`, every 15-bit string has, at some
    length, its leading bits equal to a code that decode's test accepts. With `prefix_free`, that length is unique.
    - The proof tiles [0, 2^15) by the per-length intervals, using next_code[ℓ+1] = 2·F ℓ.
    - No new mutant was run for it. The shift-0 mutant breaks `nextCodes_succ`, which it rests on.
  - Mutants, each on the definition AND its restatement together (Huffman's loop and Kraft's step):
    - shift by 0 instead of 1 is red inside `ncLoop_inv` (df-mutant-011);
    - `left' ≤ 0` instead of `< 0` is red inside `leftLoop_eq` (df-mutant-012);
    - the unmutated concatenation in the same sub-namespace is GREEN (df-mutant-010).
- `VIRDeflate/Spec.lean` (the rest group): S2, S3 and S5–S8, in two readings (`inflateLit`, `inflate`) by DEFLATE-E1. Below.
- `VIRDeflate/Run.lean` (the rest group): **GENERATED by `deflate/gen_run.py` from the corpus bytes**, digest-checked against

  exactly the manifest's bytes, or REJECT. The reasons are printed by `#eval` into `logs/df-007.log`, not asserted (S8).
- **Axioms** (df-audit-003): 29 of 29 theorems are within the standard three (3 at propext · Classical.choice · Quot.sound,
